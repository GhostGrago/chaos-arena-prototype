# Prototype 0.1.4 — 完整对局、主角轻跟随与武器拾取

Status: `TESTED_BUILD — HANDS-ON TUNING REQUIRED`  
Date: 2026-09-01

## 用户确认的版本边界

- 不增加开局倒计时，比赛立即开始。
- 最后一条库存生命耗尽后立即停止战斗、显示胜者，并允许按 `R` 重赛。
- 镜头以整张战斗平台为主，只少量、平滑地跟随本机主角；不使用双角色动态中心或大范围缩放。
- 加入三种差异明显的场内拾取武器。

## 已实现

### 比赛闭环

- 双方仍为三条库存生命；非最终出界会重生并获得0.9秒保护。
- 最终淘汰不会自动补回生命；失败角色退出场景，双方输入与物理战斗停止。
- 结算显示胜者和本局时长。
- `R` 清除旧子弹、恢复双方生命/位置/基础枪、刷新拾取点并立即开始新局。

### 镜头

- 镜头锚点保持在竞技场中心。
- 本机主角只贡献约13%的横向位置与约9%的纵向位置，且被限制在很小范围内。
- 使用平滑阻尼移动；大幅击飞不会把整个战斗平台拖离主画面。
- 未来联机时，每台客户端可将目标替换为本机拥有角色。

### 三种拾取武器

- `PULSE SMG`：青色，32发，高射速、低单发击退，适合持续压制。
- `SCATTER`：粉色，8发，每次5弹丸、近距离散射，适合近身爆发。
- `ROCKET`：黄色，5发，慢速、范围爆炸和强击退，适合平台边缘压力。
- 左、上、右三个固定拾取点约10秒刷新；有限弹药耗尽后自动回到无限弹药基础枪。
- HUD显示当前武器与剩余弹药。
- AI只在附近检测拾取物，并按难度概率争夺；不全图读取未来刷新。

## 验证结果

- Unity 6000.5.10f1 Windows Development Build 成功。
- 专项烟雾断言实际执行并通过：三个拾取点、三次出界后的最终淘汰、正确胜者、重赛恢复双方三条生命/活动状态/基础枪。
- 日志出现 `CHAOS_ARENA_014_ASSERTIONS_PASS`、`CHAOS_ARENA_SMOKE_READY` 和 `CHAOS_ARENA_SMOKE_PASS`，未匹配到运行异常。
- 真实窗口检查确认0.1.4标题、三种拾取物、武器/弹药HUD、2.5D材质和平台主导构图正常。

## 仍需试玩

- 三把武器的弹药、射速、击退和刷新时间是否公平。
- 火箭范围是否过强，散射枪近距离是否会过快清空一条生命。
- 0.9秒重生保护是否足够且不会让玩家误解。
- 主角轻跟随幅度是否舒适，强击飞时是否还需要屏外方向提示。
