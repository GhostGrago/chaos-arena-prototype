# Prototype 0.2.6 — 平台、回场与狙击手感

Status: `BUILT / SMOKE TESTED / HANDS-ON FEEL REQUIRED`
Date: 2026-09-02

## 目标

略微增加落脚与交战空间，并延后场外死亡判定，让被击飞的玩家有时间使用空中操作和二段跳尝试回场。

## 修改

- 全部七个战斗平台只在X轴统一乘以 `1.10`。
- 主平台宽度由19变为20.9；其余单向平台同样精确增加10%。
- 平台中心、高度、厚度、材质、穿透规则和出生点不变。
- 主机权威出界边界由 `|x| > 13 / y < -6` 放宽为 `|x| > 19 / y < -9.5`。
- 放宽后的主平台边缘约为 `|x| = 10.45`，到横向死亡线保留约8.55单位恢复空间。
- 不使用客户端屏幕边缘作为判定，因为联机时每台客户端的轻跟随镜头不同。
- 狙击枪基础击退由 `(6.4, 2.2)` 小幅提高到 `(7.0, 2.4)`，强化单发命中存在感。
- 狙击枪冷却由1.5秒延长到1.7秒，让高击退以更慢射速为代价。
- 狙击枪伤害保持10、弹速保持46、弹药保持3发，避免内部伤害再次过快推高全局击退倍率。
- 背景保持0.2.5版本；被否决的透明云影和雾层没有恢复。
- HUD版本标识更新为 Prototype 0.2.6。

## 回归保护

- 烟雾测试逐个平台检查运行时X轴宽度与 `ArenaBuilder.Layout` 一致，检查死亡线为回场保留足够空间，并守住狙击枪“更强击退、更慢射速、伤害不增加”的定位。
- 弹丸出膛、击退控制锁、透明材质、随机掉落、机器人、淘汰、胜者和重赛等原有断言继续运行。
