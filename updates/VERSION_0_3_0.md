# Prototype 0.3.0 — 本地多人、手柄与显示设置原型

Status: `BUILT / SMOKE TESTED / HANDS-ON REQUIRED`
Date: 2026-09-02

## 目标

在保留单人对AI和Relay在线模式的同时，增加同一台电脑上的两至三人对战，让当前已经成形的核心玩法更容易被朋友当面试玩。

## 本地双人规则

- 主菜单新增 `LOCAL 2 PLAYERS`。
- 固定两名本地真人，不添加AI。
- P1键盘：`A/D`移动、`Space`跳跃、`S`下穿、`J`或左Ctrl射击。
- P2手柄：第一只手柄左摇杆移动、A跳跃、B或摇杆下下穿、X或RB射击。
- P2的LT与RT也都可持续射击；X/RB继续作为后备键。
- P2备用键盘：方向键移动/跳跃/下穿，右Ctrl或小键盘0射击。
- 本地双人使用共享竞技场镜头，焦点取两人中点并根据最远位置、高度和横向间距适度拉远。
- 两名玩家分别显示P1/P2屏外方向提示。

## 本地三人扩展

- 主菜单新增`LOCAL 3 PLAYERS`，固定三名真人且不添加AI。
- P1使用键盘，P2分配第一只Gamepad，P3分配第二只Gamepad。
- Xbox与DualSense统一操作语义：左摇杆移动、南键（A/Cross）跳跃、东键（B/Circle）下穿、LT/RT射击，西键与右肩键仍可射击。
- 共享镜头支持三个目标，以三人中心、最远横向间距和最高位置计算跟随与拉远。
- P1/P2/P3各自拥有屏外提示；手柄数量不足时游戏内显示连接警告。
- 主菜单显示实时手柄数量及P2/P3设备名称。

## 技术边界

- 键盘与既有逻辑继续使用旧Input Manager；两只手柄使用Unity Input System 1.19.0，项目启用Both模式。
- 1.17.0在Unity 6000.5.10f1中因包编辑器代码调用已废弃API而编译失败，已改用可正常构建的1.19.0，未修改包源码。
- Host/Join座位映射保持不变；本地模式只在Offline会话中把HumanSeats设为2或3。
- 从在线客户端返回本地模式时，座位所有权会恢复到本机Seat 0。
- 本版本不包含手柄改键、震动、多手柄分配或菜单手柄导航。

## 同里程碑内的反馈整合

- 用户已确认P2移动和A键跳跃通过实体手柄测试。
- 射击按武器产生真实的反向刚体速度，并以0.055–0.12秒的短窗口防止移动控制立刻抹掉后坐动量。
- Pulse SMG后坐最轻，Carbine轻微，Scatter明显，Sniper最强；具体距离仍需真人调校。
- 主菜单和暂停菜单新增显示设置入口。
- 可选720p、900p、1080p、1440p、4K以及当前显示器原生分辨率。
- 可切换窗口模式和无边框全屏，选择保存到PlayerPrefs并在下次启动恢复。
- 1440p/4K下自动缩放IMGUI，避免菜单和HUD过小。

## 保留的0.2.6调整

## 2026-09-03 批次：击中表现、AI难度、界面、地图与道具

用户已确认三人实体输入实战通过（键盘 + Xbox + DualSense 同时游玩），0.3.0 的三人实战验收项完成。

### 击中与速度表现

- 命中新增冲击环与沿真实冲量方向的火星扇形；旧版只用水平正负号，向上击飞时火星仍朝两侧喷。
- 速度拖影由「一片片残影」改为单条连续 `TrailRenderer` 光带：残影在竞技场距离下读作虚线，连续光带既像动态眩光，也便于多人同屏时定位被击飞的人。
- 阈值 9.5（跑速上限为 7），所以正常走位不产生拖影；长度与宽度随速度连续变化，命中时短暂强制开启。
- 命中瞬间的一次性残影群与网格残影两套实现均已移除，改为提升角色自身的连续光带。

### AI 五档难度

- `BotDifficulty` 由三档扩为五档：EASY / NORMAL / HARD / EXPERT / MASTER，全部数值集中到 `BotProfile.cs`。
- 整条曲线上移一级：新 EASY 等于旧 NORMAL，新 NORMAL 等于旧 HARD；默认档位由 EASY 改为 NORMAL。
- 命中率提升靠四项机制而非数值作弊：弹道飞行时间预判、视线遮挡检测、按武器有效射程拒绝远射、瞄准解算需保持一段反应时间。
- 走位提升靠三项：按当前武器拉开对应距离、走路前探地避免自己掉出场、被击飞后用二段跳回场。
- 新增 `PrototypeProjectile.Active` 在飞行弹丸列表，供高档位 AI 闪避。
- 按键 F1–F5，ESC 菜单五档（面板宽度 360 → 430，否则 NORMAL/EXPERT 会被截断）。

### 界面

- 移除竞技场底部常驻的操作与规则文字，移入主菜单「HOW TO PLAY」。
- HUD 改为生命计分卡：不再显示血量，真人一律左上角，机器人右上角，四人同乐时四张卡同在左上。
- 主菜单简化为 SINGLE PLAYER / MULTIPLAYER 两个入口加设置。
- 新增本地大厅：手柄按 A/Cross 占座，P1 按 ENTER 开始；在线房间移入大厅的子页面。
- 本地人数上限由 3 提升至 4（P1 键盘，P2–P4 手柄 0/1/2），共享镜头支持四目标。
- 本地多人现在也可以加机器人补位。

### 武器表现

- 冲锋枪、霰弹枪、狙击枪三把枪的模型方向修正（枪口原本朝向自己）。手枪经实测正确未改动。
  方向标记改为以实机表现为准：OBJ 导入存在自身的手性转换，直接测量网格不足以推导。
- 地面浮动武器放大：`GetHeldScale × 0.62` → `× 0.95`，光环同步放大。
- 新增充能读条环：冷却 ≥ 0.3 秒的武器（手枪、霰弹、狙击）在枪口旁显示一圈逐格闭合的读条，合拢即可再次开火；
  冲锋枪 0.11 秒冷却不显示，否则只会闪烁成噪点。

### 地图与道具

- 新增四张地图主题（`ArenaThemes.cs`）：NEON CITY（原图）、DESERT、STARSHIP、OCEAN。
  各自拥有独立的平台布局、配色、天空、背景（城市 / 沙丘 / 星空 / 海面）与灯光。
- 新增移动平台：沙漠两块横向滑动、星舰一部纵向升降、海洋两侧船体反相起伏。
  运动由时钟推导而非积分，因此各端无需同步即可一致。
- `FighterMotor` 现在把脚下平台的速度并入目标速度；此前电机每步覆写水平速度，站上滑动平台会被直接刮下去。
- 平台改为「无缩放根 + 缩放甲板」结构，移动平台才能带着边缘灯与装饰一起走。
- 新增两个道具（约占掉落的三分之一）：
  - SHIELD：与出生保护同机制，减伤减击退，7 秒。
  - SHRINK：体积与碰撞体同时缩到 0.6，受击面变小，9 秒。
  两者复用同一个已复制的 pickup 字节，道具 id 从 100 起接在武器 id 之后，无需扩展网络状态。
- 移除每块平台下方的品红色辉光条（无玩法含义，读作杂散色块）。

### 本批次新增自动断言

- `AssertBotsCanActuallyShoot`：机器人必须真正得出开火解算，且重复下达同一目标不得重置反应计时器。
- `AssertBotDifficultyLadder`：五档在七个维度上必须逐档单调变强，且 `SetDifficulty` 必须传达到每一个活着的机器人。
- `AssertSpeedTrailIsWired`：每个角色的速度光带与充能环必须真的构建出来。
- `AssertEveryArenaBuilds`：四张地图逐一构建，检查主甲板为实心、每块平台与下方落差不超过 3.4、出界余量足够、镜头存在。
- `AssertPowerUpsApply`：道具 id 往返不失真、不与武器 id 冲突，且确实改变角色状态。
- `AssertMovingPlatformsCarryRiders`：移动平台必须挂载运动学刚体。

### 回归与反向验证

本批次修复了一个由本次改动自身引入的回归：`RetargetBots()` 每帧重新下达目标，而新的 `SetTarget`
每次都清空瞄准状态，导致反应计时器永远无法累积到档位所需时长——机器人会走位、会闪避，但一枪不开。

`AssertBotsCanActuallyShoot` 经反向验证：临时还原该缺陷后构建，断言以
`Re-issuing the same target reset the bot's reaction timer.` 失败且 `CHAOS_ARENA_030_ASSERTIONS_PASS` 不出现；
恢复修复后三条 marker 全部通过。
