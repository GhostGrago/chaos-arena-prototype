# Prototype 0.1.7 — 几何战士形态与抓边回场

Status: `TESTED_BUILD — HANDS-ON TUNING REQUIRED`
Date: 2026-09-02

## 批次选择理由

由Claude判断内容（用户授权）。本批只做**角色层**，不碰模式类候选（生化、转盘、逃杀）——那些需要先有 U-028 模式框架，现在做会把0.1.6刚拆干净的 `PrototypeBootstrap` 重新搞乱。

选中的四项互相配套：几何形态让刚定的身份落地，抓边给被击飞者自救手段，屏外指示让玩家知道自己在哪，收紧出界边界让前两者的价值真正体现。

## 已实现

### U-023 几何战士形态

角色从胶囊人形改为**基本立体**，`GAME_VISION` D-019 的身份正式落地。

| 玩家 | 形态 | 颜色 |
|---|---|---|
| PLAYER | 立方体 | 蓝 |
| BOT 1 | 球体 | 红 |
| BOT 2 | 四面体 | 绿 |
| BOT 3 | 圆柱体 | 紫 |

- Unity没有四面体图元，新增 `ProceduralShapes` 生成：取立方体四个交替顶点构成正四面体，每面顶点独立以保持硬边刻面。
- 每个角色带一个发光"眼"，位置随朝向翻转——抽象立体唯一的朝向线索，射击玩法必需。
- **物理胶囊完全未改**（高1.8、半径0.375），所以这是纯视觉改动，手感不受影响。

### 人格层重写：幽默来自动作

`FighterVisual` 从四肢摆动改为立体运动，兑现 D-019 里"抽象形体靠动作建立人格"的约定：

- 命中挤压、落地压扁
- **空中按移动方向翻滚**，落地回正——几何体翻滚本身就好笑
- 速度倾斜、濒死抖动（幅度随击退倍率上升）

### U-009 抓边回场

被击飞后第一次有了自救手段，兑现 `GAME_VISION` 设计支柱2"可学习的回场技术"。

- 下落且非落地状态时，若头部处于平台边缘的抓取窗口内（边缘外0.62单位内、平台顶面下方1.1单位内），自动抓住。
- 抓住后速度归零、恢复二段跳、朝向自动转向平台。
- **`Space` 蹬上去**，**`S` 或超时1.25秒松手**。
- 松手后0.55秒内不能重新抓，防止吊在边缘拖时间。
- 抓取判定抽成纯函数 `FighterMotor.TryFindLedge`，不依赖组件状态，因此可以被烟雾测试直接验证。

### U-011 屏外方向指示

本机玩家被击飞出画面时，屏幕边缘显示 `YOU ▸` 标记指向其位置（含摄像机后方的翻转处理）。镜头刻意不追人以保住场地全景，这个指示补上代价。

### U-017 出界边界与火箭穿台

- 出界边界从 `|x|>16 / y<-7` 收紧到 **`|x|>13 / y<-6`**。旧边界让角色在画面外很远处才判定死亡，配合抓边后收紧既公平又看得见。
- 弹丸现在像角色一样从下方穿过单向平台，修复**火箭在单向平台底面引爆**的问题。

## 仍需试玩确认

构建与烟雾通过**不等于**手感通过。以下未经人工验证：

- **抓边的判定窗口是否舒服**——太窄会抓不住，太宽会误抓。这是本版最需要真人验证的一项，烟雾只能证明判定函数在给定坐标下工作。
- 1.25秒挂边上限与0.55秒冷却是否合理。
- 几何形态的可读性：四个形状在混战中是否真的比原来好分辨；发光眼是否足够指示朝向。
- 空中翻滚幅度是否过头、会不会看着晕。
- 收紧后的出界边界是否太严苛。
- 遗留未处理：U-015散射贴脸过强、U-016火箭无自伤——两者都需要在新地图上重测后再定。
