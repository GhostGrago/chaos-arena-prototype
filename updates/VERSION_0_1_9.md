# Prototype 0.1.9 — 果冻质感、降光与碎裂爆开

Status: `TESTED_BUILD — HANDS-ON TUNING REQUIRED`
Date: 2026-09-02

## 用户反馈驱动

0.1.8 试玩后反馈：光效过强有"光污染"感；希望角色改成果冻质感；死亡与高伤应当爆炸碎裂；子弹命中动画要更好。

## 抄袭风险判断（用户提问的直接回答）

**风险取决于剪影，不取决于材质。**

- **果冻人形**风险高：Fall Guys 的软糖豆人已占据"派对游戏 + 果冻小人"的组合认知，Gang Beasts 亦在此区间。
- **果冻材质 + 几何剪影**不构成撞车：Fall Guys 的身份是豆子的**轮廓**，而非"柔软"这一属性。半透明会颤动的立方体、球体、四面体没有既有作品占据。

因此保留 D-019 的几何剪影，仅更换表面与动作语言。这同时缓解了 D-019 中记录的"纯硬几何容易显冷"风险。

## 已实现

### 降低光污染

| 项目 | 0.1.8 | 0.1.9 |
|---|---:|---:|
| Bloom 阈值 | 0.85 | **1.15** |
| Bloom 强度 | 1.35 | **0.5** |
| 对比 / 饱和 | +14 / +12 | +10 / +8 |
| 平台边缘条 | 3.4 | 1.7 |
| 角色边框 | 3.0 | 1.6 |
| 朝向眼 | 4.0 | 2.0 |

阈值提高意味着只有真正的发光体才进入 Bloom，普通表面不再整体泛白。

### 果冻材质

新增 `PrototypeMaterials.AssignJelly`：运行时把不透明模板切换为透明混合，alpha 0.78、金属度 0、光滑度 0.92。

**容错设计**：若某个 URP 变体拒绝该切换，实体只会保持不透明，仍然可读——霓虹边框始终不透明，剪影不依赖材质是否成功。

### 果冻颤动（比半透明更关键）

`FighterVisual` 新增弹簧阻尼抖动：以速度变化量为冲量，刚度 110、阻尼 7.5、幅度上限 0.3。落地、受击、急转都会让身体弹动并自行收敛。

**这才是"软"的主要来源**，半透明只是辅助。

### 碎裂爆开

新增 `CombatVfx.JellyBurst`：生成翻滚、受重力、逐渐缩小消失的果冻碎块，使用角色本体颜色。

| 触发 | 碎块数 | 尺寸 | 力度 |
|---|---:|---:|---:|
| 最终淘汰 | 30 | 1.15 | 9.0 |
| 掉一条命 | 18 | 0.9 | 7.0 |
| 重击（击退权重>0.45） | 4–12 | 0.5–0.85 | 5.5 |
| 子弹命中 | 5 | 0.42 | 4.2 |
| 火箭范围命中 | 8 | 0.55 | 6.0 |

轻微擦伤**不会**触发碎裂，保证爆开这个反馈始终有分量。淘汰与掉命同时触发满强度 hitstop。

子弹命中的飞溅使用**被击中者的颜色**，因此命中读作"从那个角色身上打下来的果冻"，而非通用火花。

## 仍需试玩确认

- 降光后是否仍偏亮或已经偏暗。
- 果冻半透明在实机上是否正确渲染（本地无法目视确认，若角色发灰或穿透异常请立即反馈）。
- 颤动幅度 0.3 是否过软或不够软。
- 碎块数量在 3 人机混战时是否造成视觉噪声或掉帧。
- 遗留未处理：U-009抓边（需先做AI挂边感知）、U-015散射贴脸、U-016火箭无自伤。
