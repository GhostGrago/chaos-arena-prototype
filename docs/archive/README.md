# Project documentation archive

These files preserve historical evidence, prototype scopes, policies and version plans. They are not required for normal project startup.

## Root-level history

- `ASSET_POLICY.md` — historical asset-handling policy.
- `EVIDENCE_INDEX.md` — build and investigation evidence through Prototype 0.1.3.
- `PITFALLS.md` — resolved implementation pitfalls.
- `PROTOTYPE_01.md` — original Prototype 0.1 scope.

## Version history

The `updates/` subdirectory contains the full historical candidate pool, the 0.1.2 and 0.1.3 plans, the earlier update workflow notes and the network-duel proposal.

Read archived files only when a current task needs their specific history.
