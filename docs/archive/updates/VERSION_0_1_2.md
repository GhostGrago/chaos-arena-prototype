# Prototype 0.1.2 — 基础战斗手感与AI难度

Status: `TESTED — HANDS-ON TUNING REQUIRED`  
Date: 2026-09-01

## 版本目标

稳定基础混战手感：让上层平台成为可上下穿越的战术路线，取消玩家身体推挤，隐藏测试用战斗数字，适度放慢受击累积速度，并提供默认Easy的机器人难度预设。

## 拟纳入范围

1. 将左、右和顶部平台标记为单向平台；主地板保持永久实体。
2. 角色上升时从下方穿过单向平台，下降时落在平台上。
3. 站在单向平台时，按一次 `S` 或方向键下穿过当前平台。
4. 下落只忽略当前支撑平台，不影响其他玩家，也不会自动连续穿过下一层。
5. 机器人在目标位于下层且路线安全时可以使用相同的下落动作。
6. 用平台厚度与边缘颜色区分主地板和可穿越平台。
7. 增加单向穿越、主动下落、主地板保护、多玩家隔离和机器人下落的验证。
8. 玩家与玩家、玩家与机器人之间不发生实体推挤或阻挡，但攻击命中仍正常。
9. 为角色重叠增加必要的配色、轮廓或轻微视觉景深区分，不改变2D物理位置。
10. HUD 移除 HP 和击飞倍率数字，只保留玩家身份与剩余生命。
11. 用命中反馈、身体不稳定状态和强击飞拖尾表达危险程度，而不是显示后台数字。
12. 基础子弹的后台累积候选值从 11 降至 9；基础击退及 1.0x–3.5x 曲线暂不改变。
13. 增加 Easy、Normal、Hard 三档机器人行为预设，当前默认 Easy。
14. 难度只调整反应间隔、射击段、停火窗口、移动决策和平台路线积极程度，不修改移动/武器/生命等角色属性。
15. 原型保留快速切换难度的测试入口，允许在同一构建中隔离比较 AI 行为与伤害累积变化；不制作完整难度菜单。
16. 基础枪增加轻量物理后坐、枪身回弹、枪口闪光和程序生成开火音。
17. 子弹增加更清楚的弹体和短拖尾；命中角色或场景时产生不同火花，角色命中时闪白。
18. 受击累积较高时角色产生非数字的轻微不稳定动作。
19. 射速、弹速、伤害、击退、后坐和颜色进入统一武器配置；本版不增加第二把枪。

## 明确不纳入

- 抓边、攀爬或墙跳；
- 新武器、Buff、抽奖事件或联网；
- 重做整张地图；
- 改变基础击退、最大击飞倍率、生命数和射速；
- 为所有武器统一决定平台穿透规则。
- 通过增加机器人伤害、速度、生命或无视冷却来制造难度；
- 完整的主菜单、关卡选择或长期AI自适应系统。

## 验收条件

- 三块上层平台均能从下方穿越并从上方站立。
- 下键只穿过当前一层，按住不会连续漏层。
- 主地板无论何时都不能用下键穿过。
- 一名角色下落不改变另一名角色的平台碰撞。
- 上升击飞和下降落台符合相同规则。
- 机器人能执行下落且不会明显增加无意义坠落。
- 玩家身体可以互相穿过，攻击命中、平台碰撞和重生仍正常。
- 玩家重叠时不会卡位，并且仍能区分角色身份。
- HUD 不显示 HP 或击飞倍率，只显示身份与剩余生命。
- 后台累积仍控制击飞强度，基础子弹候选值为 9，重生后正确重置。
- 没有数字时，玩家仍能通过非数字反馈理解自己越来越容易被击飞。
- 新开局默认使用 Easy，且有可感知的反应与停火窗口。
- Normal 和 Hard 的压力逐级提高，但三档使用相同角色/武器数值且不读取未来输入。
- 三档机器人都能适应单向平台，不会明显增加无意义坠落。
- Windows 构建、运行冒烟测试和实际试玩均通过，无新增紫色材质或运行异常。

## 验证结果

- Unity 6000.5.10f1 Windows Development Build 成功。
- 无界面运行初始化通过，日志出现 `CHAOS_ARENA_SMOKE_READY` 与 `CHAOS_ARENA_SMOKE_PASS`，未发现运行异常。
- 真实 Windows 窗口检查确认材质、2.5D 场景、0.1.2 HUD、默认 Easy 和新控制提示正常显示。
- 物理穿台、下落可靠性、三档 AI 主观差异、后坐强弱和命中清晰度仍需玩家实际连续试玩，不以构建成功替代手感结论。
