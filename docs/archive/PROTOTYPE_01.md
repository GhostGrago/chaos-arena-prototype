# Prototype 0.1 — 单人机器人击飞沙盒

## 要回答的问题

最少的一套规则能否让“连续命中令对手越来越容易被击飞，最后掉出场外”在一张平台地图中产生清楚、可控并且有反击机会的乐趣？

## 本版范围

- 一张由中央地面和三层平台组成的灰盒地图。
- 一名键盘玩家和一名使用相同移动、跳跃、射击接口的机器人。
- 水平朝向射击。
- 移动、二段跳、命中、伤害、击飞、越界、扣命和重生。
- 100 点生命、3 条命；生命为 0 不死亡。
- 击飞倍率：`lerp(3.5, 1.0, health / 100)`。

## 明确不做

- 联机、Steam 房间与匹配。
- 多武器、箱子、稀有装备、背包和元素连锁。
- 抓边、多段跳配置、PvE、正式 AI、正式 UI 和正式美术。
- 旧 Flash 游戏提取素材或来源不明的网络素材。

## 通过标准

- 玩家与机器人都能完成移动、二段跳和水平射击。
- 命中只降低生命并施加随生命下降而增强的击飞，不在 0 生命时判死。
- 越界稳定扣除一条命并重生。
- 项目在固定 Unity 版本中无脚本编译错误，场景可进入 Play 模式。
- 连续试玩能识别至少一组需要调整的移动或击飞数值。

## 下一门槛

只有本闭环通过手感试玩后，才进入 Prototype 0.2：武器差异、箱子和最少三种连锁反应。
