## 0.3.0整合内容

- 本地2人和3人名单、三套独立输入、无AI本地对战。
- 双/三目标共享镜头，根据所有本地玩家中心、最高位置和最远横向距离跟随与拉远。
- P1/P2/P3屏外提示。
- Unity Input System 1.19.0；`activeInputHandler=Both`以保留旧键盘逻辑。
- Input System 1.17.0在Unity 6000.5.10f1下因包编辑器源码调用已废弃API而编译失败，已弃用；不要降级回1.17.0，也不要修改PackageCache源码。
- 武器射手后坐力现在产生真实反向刚体速度，并以短暂控制锁保留动量。
- 平台横向加宽10%，出界线放宽到`|x|>19 / y<-9.5`，狙击枪击退`(7.0,2.4)`、冷却1.7秒。
- 显示设置支持720p、900p、1080p、1440p、4K和显示器原生分辨率；支持Windowed/Borderless、PlayerPrefs持久化和1440p/4K UI缩放。

## 四个不能回退的缺陷

1. 弹丸出膛自毁：装饰primitive碰撞体必须先`enabled=false`再`Destroy`；保留`AssertProjectileSurvivesItsOwnMuzzleFlash`。
2. 击退被移动控制抹掉：保留`FighterMotor`受击控制锁与轻阻力；现在射手后坐力也依赖短暂动量窗口。
3. URP透明材质静默失败：果冻透明状态来自`PrototypeJelly.mat`资源，不在运行时猜混合参数；保留透明关键字/队列断言。
4. 连接批准期间误判断线：客户端必须曾经成功连接后，后续断开才算掉线；不要删除`wasConnected`门槛。
